How the numbers are checked

Four gates between a vendor row and your inbox.

Each gate is plain Python with fixed constants. No model decides whether a figure passes.

Problem

A number can trace to a real field and still be impossible.

The FMP price field sometimes holds the trade total instead of a unit price. Shares times price then gives a figure that traces to the filing and is false.

Issuer / filersharesprice fieldshares x price
MetLife / FINS40,000,00040,000,000$1,600,000,000,000,000
Sutherland / PSX3,5232,110,482$7,435,228,086

Both rows are fixtures in the test suite.

Solution

Check provenance and plausibility separately.

"Provenance only" is a pipeline that only asks where a number came from. "Whale Agent" is this pipeline. Select a gate to see its constants and source.

Hover, focus or tap a gate.

The only model in the pipeline is the optional summary writer. Gate 3 filters its sentences. These gates stop figures that are impossible. A figure that is wrong but possible still gets through.
