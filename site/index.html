The agent that
reads what
investors must
disclose

Company executives, hedge funds, activists and members of Congress have to report what they buy and sell. The agent reads those reports from the US, Japan and Taiwan, prices each one in US dollars, and emails you a short brief that you set up yourself.

View on GitHub Get the free brief

Install via terminal

curl -fsSL https://whale-agent.com/install | sh

Then run whale to open the settings.
